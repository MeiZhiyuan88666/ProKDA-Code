# Learn Before You Judge: Progressive Knowledge-to-Decision Alignment for Explainable Hateful Meme Detection

This repository provides **partial anonymous code** associated with the paper:

**“Learn Before You Judge: Progressive Knowledge-to-Decision Alignment for Explainable Hateful Meme Detection.”**

The code is released for the purpose of anonymous peer review, mainly to provide implementation evidence for the proposed method.

Please note that this repository **does not contain the complete implementation required for full reproduction of the paper**. Some components, scripts, configurations, and auxiliary resources have been omitted during the anonymous review stage.

The complete codebase, including detailed instructions and necessary resources, will be released after the review process.

All identifying information has been removed to preserve anonymity.
